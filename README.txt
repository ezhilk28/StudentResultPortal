# Student Result Portal

A Data Structures project developed using HTML, CSS, JavaScript, and C++.

## Features
- Student Login
- Result Display
- Percentage Calculation
- Grade Calculation
- Pass/Fail Status
- PDF Download
- Responsive Design

## Data Structure Used
unordered_map<string, Student>

## Time Complexity
Search: O(1)

## Run
Open index.html using Live Server.
